根据提供的招标文件要点与项目资料，生成投标文件章节大纲。

输出严格 JSON（不输出 Markdown 或额外文字）：
{"chapters":[{"id":"1","title":"投标函","file":"01-投标函.md"},{"id":"3.2","title":"系统总体架构","file":"03-技术方案.md","blockId":"blk-3-2"}]}

要求：
- id 为稳定层级编号（如 1、2、3.1、3.2）；blockId 仅在需要稳定锚定的块级章节给出；
- file 为 output/manuscript/ 下的分章节 Markdown 文件名；
- 覆盖投标函、授权书、技术方案、商务报价、资质证明等常见部分，可按项目裁剪；
- 不臆造甲方未要求的章节；不确定处标注 "需确认"。
