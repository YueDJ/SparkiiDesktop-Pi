# 主进程日志落盘 + 级别 + 设置查看 实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 让主进程关键日志（尤其 `[runtime] verify` / `ensure failed`）落盘到 JSONL 文件，并支持日志级别过滤；设置界面里让「日志级别」真正生效并新增「查看日志」区。

**Architecture:** 复用现有 `Logger`（已写 JSONL），给它补 `debug` 级别、级别阈值与 console 双写；把 `index.ts` 启动路径的裸 `console.log/error` 改为 `logger.log`；`logLevel` 存进现有 `settings.json`，保存时热更新 `logger.level`；`SettingsView` 的 runtime pane 让日志级别下拉受控并展示 `diagnostics().logs`。

**Tech Stack:** TypeScript（Electron main）、React（renderer）、vitest、现有 `@sparkii/ui` 组件。

**Spec:** 对话中确认的最小闭环三步（无独立 spec 文件）：① Logger 补 debug + 阈值；② 主进程 `console.log/error` 接入 Logger；③ 设置里日志级别生效 + 查看日志。文件形式保持 JSONL 不变。

## Global Constraints

- 日志文件保持 `data/logs/sparkii.log.jsonl`（JSONL），每行 `{ ts, level, msg, ctx? }`，`ts` 为毫秒时间戳。
- 级别 `debug < info < warn < error`，默认阈值 `info`；低于阈值的记录丢弃（不落盘、不 console）。
- 日志写盘失败不阻断主流程（`Logger.log` 内部吞错）；console 双写保持 dev terminal 可见。
- `logLevel` 存现有 `settings.json`，保存即生效（`logger.level` 热更新，无需重启）。

- [ ] **Step 3: 实现** `logger.ts`

```ts
import { appendFile, mkdir, readFile } from 'node:fs/promises';
import { join } from 'node:path';

export type LogLevel = 'debug' | 'info' | 'warn' | 'error';

const LEVEL_RANK: Record<LogLevel, number> = { debug: 0, info: 1, warn: 2, error: 3 };

export class Logger {
  level: LogLevel = 'info';
  constructor(private dir: string) {}
  private file() { return join(this.dir, 'sparkii.log.jsonl'); }
  async log(entry: { level: LogLevel; msg: string; ctx?: Record<string, unknown> }): Promise<void> {
    if (LEVEL_RANK[entry.level] < LEVEL_RANK[this.level]) return;
    if (entry.level === 'error') console.error(entry.msg, entry.ctx ?? '');
    else if (entry.level === 'warn') console.warn(entry.msg, entry.ctx ?? '');
    else console.log(entry.msg, entry.ctx ?? '');
    try {
      await mkdir(this.dir, { recursive: true });
      await appendFile(this.file(), JSON.stringify({ ts: Date.now(), ...entry }) + '\n');
    } catch {
      // 日志写盘失败不阻断主流程
    }
  }
  async export(): Promise<string> {
    try { return await readFile(this.file(), 'utf8'); } catch { return ''; }
  }
}
```
