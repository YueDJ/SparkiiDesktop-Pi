# Pi Agent 1.5.0 Upgrade Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Upgrade Sparkii's embedded Pi kernel from `1.0.2` to `1.5.0` without changing existing tool, approval, session, skill, or provider behavior.

**Architecture:** Pin the Pi package exactly at `1.5.0`, keep the existing `customTools + noTools: "builtin" + setActiveTools` assembly, adapt only where the 1.1–1.5 public API changed, and prove compatibility through real, offline SDK tests plus the desktop bundle build.

**Tech Stack:** TypeScript, Node >= 22.19, pnpm workspace, Vitest, esbuild, Electron, Pi SDK 1.5.0.

**Spec:** `docs/superpowers/specs/2026-11-05-pi-1.5-upgrade-design.md`

## Global Constraints

- Target exact package version: `@earendil-works/pi-coding-agent@1.5.0`.
- All transitive `@earendil-works/*` runtime packages resolved by the lockfile must also be `1.5.0`.
- Keep `cacheWarming: "off"`.
- Do not register or activate `codemode`, `tool_search`, MCP, virtual models, or Pi self-update.
- Tool visibility must be exactly the current saddle: no missing tools, default tools, or previous-saddle leakage.
- Unknown saddle tools fail closed and clear the previously visible tool set.
- All tool actions continue through Main Runtime Actions / Proposal paths; do not trust Pi or model-reported authorization.
- `CURRENT_SESSION_VERSION` remains `3`; do not add a session migration.
- Work happens on branch `codex/pi-1.5-upgrade`.

```ts
export function projectSaddlePromptInput(
  event: Pick<BeforeAgentStartEvent, "systemPrompt" | "systemPromptOptions">,
  saddle: SessionSaddle | null,
) {
  return {
    systemPrompt: event.systemPrompt,
    systemPromptOptions: {
      ...event.systemPromptOptions,
      cwd: promptWorkingDirectory(saddle, event.systemPromptOptions?.cwd),
      workspaceRoot: saddle?.workspaceRoot,

  };
}

pi.on("before_agent_start", (event: BeforeAgentStartEvent) => {

  return applySaddleSystemPrompt(
    getSystemPrompt(),
    projectSaddlePromptInput(event, getSaddle()),
  );
});
```
