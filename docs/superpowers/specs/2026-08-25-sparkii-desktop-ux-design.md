# Sparkii Desktop UX/UI 设计规格

- 日期:2026-08-25
- 状态:已与用户逐屏确认(可视化决策)
- 范围:Sparkii Desktop 桌面端 UI/UX(壳层、三种智能体表面、审批、审计、首页、登录、状态栏/队列、视觉风格)

## 1. 目标与定位

Sparkii Desktop 是本地部署、可审计的 AI 桌面工作台,当前 pilot 为合同审核,未来承载多种垂直智能体。主要用户是业务人员(法务/风控/采购等),技术管理员为次要用户。产品卖点:可控(写操作人工批准)、可审计(全程留痕)、本机运行(数据不出本机)。

## 3. 信息架构

```
顶栏:应用身份 | 当前智能体 | ●本机 · 审计✓ | 审批角标 | 设置
左栏:已安装智能体(状态点/排队徽标)+ 审批 / 审计入口
表面头部:智能体 · 会话 [会话▾] [新会话] [暂停/打断]
表面区:三种范式之一(任务流 / 对话 / 仪表板)
底部状态栏:一句话状态 | 运行 3/4 · 2 排队 ▾ | 技术信息(hover 展开)
全局抽屉:审批中心 P3 · 审计时间线 T1 · 会话抽屉 A1 · 队列面板 S3
```

## 4. 关键交互与状态

- 运行状态:运行中(蓝)、排队(橙)、等待审批(琥珀)、完成(绿)、失败(红)、重连中。
- 上下文近满:提示条"本任务快记满了,建议开新会话继续"+ 按钮;不默认展示百分比。
- 模型降级:显示"当前使用备用模型";云端模型显示"数据将离开本机"。
- 发送按钮三态:空闲=发送,运行中=停止/打断,有附件=显示文件数。
- 审批:倒计时、冻结参数可展开、意见、拒绝/批准;高风险二次确认;超时自动拒绝。
- 排队:触发时提示"已为你排队(第 1 位),空出后自动开始";可取消/稍后提醒;轮到通知。
- 空态即引导:无智能体时引导安装;无模型时引导配置端点。
- 模型配置:服务商切换即切换端点与模型列表;拉取模型只返回当前节点;测试连接对当前节点全部模型做健康检查;任务路由按节点配置。

## 5. 范围与边界

本设计覆盖:壳层、三类表面、审批、审计、首页、登录、状态栏/队列、视觉系统。不覆盖(接口预留):多用户 SSO UI、硬沙箱 UI、智能体市场完整流程、深色模式。

## 6. 开放问题

- 智能体安装/市场页详设(后续)。
- 通知策略(声音/桌面通知)细节。
- V2 深色工程风是否作为正式可选主题提供。

## 7. 落地顺序建议

1. 设计文档固化(PRODUCT.md / DESIGN.md / 本规格)——已完成。
2. 高保真可交互原型(HTML/CSS,验证交互与视觉)。
3. 按原型实现壳层与 token 系统(packages/theme 扩展)。
4. 按表面范式逐个落地:合同审核(任务流)→ 对话 → 仪表板。
5. 审批/审计/队列等信任组件。
