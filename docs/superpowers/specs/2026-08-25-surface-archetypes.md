## 1. 对话式表面(法规问答,C1)

### 定位

面向业务人员的问答型智能体:像聊天一样提问,Agent 检索本地法规库后作答;工具调用透明但不抢戏。

### 布局

```
表面头部:法规问答 · 会话#1 [会话▾] [新会话]
消息流(占满宽度,气泡自适应):
  用户气泡 → 靠右,主色底、白字,右下小圆角
  智能体气泡 → 靠左,表面底、细边框,左下小圆角
  工具卡片 → 消息流内,虚线边框 + 浅蓝底,可展开命中明细
Composer(固定底部,不随消息滚动):
  [输入框(多行, Ctrl+Enter 发送, 草稿本地保留)] [附件图标] [发送/停止]
```

### 交互

- 发送按钮三态:空闲=发送图标;生成中=停止图标(点击中断,显示"已停止生成");完成=回到发送。
- 新会话:头部图标按钮 + 会话抽屉内"+ 新会话";点击清空当前消息流。
- 工具调用内联卡片:显示工具名与结果摘要("knowledge.search · 6 条 ▸"),点击展开命中列表(可再展开原文片段)。
- 会话抽屉:仅展示当前智能体的会话,点击行回到对应表面。
- 错误:prompt 失败显示 alert 行,保留用户输入可重发。

### 依赖后端

- `prompt(sessionId, text)` 流式事件(`chat-event` message/delta/text)
- 工具事件(`tool_call` / `tool_result`)以绑定到消息的卡片形式下发
- 附件上传(read 工具)、会话历史接口

## 2. 仪表板式表面(舆情监控,D1)

### 定位

面向业务人员的监控型智能体:打开先看"今天有没有要处理的事",再往下钻细节。

### 布局

```
表面头部:舆情监控 · 会话#2 [会话▾] [新会话] 近30天▾ 定时:每日9:00 刷新
指标卡行(4 卡):风险条目 / 新增 / 高关注 / 已出报告
主趋势图:风险条目/日(柱状/折线),数据来源标注(本地知识库)
明细表:标题 | 来源 | 等级 | 时间
底部状态栏:● 舆情监控已更新 10:32 · 运行 3/4 · 2 排队
```

### 交互

- 时间范围选择、手动刷新(按钮带加载态)、定时刷新(可配置,默认每日 9:00)。
- 明细表行可点击进入单条详情(后续);等级用语义徽标(高红/中橙/低绿)。
- 空态:无数据时显示"暂无监控数据,检查数据源或等待定时任务"。
- 数据来源徽标常驻(本地知识库/连接器),呼应"数据不出本机"。

### 依赖后端

- 指标聚合接口、趋势序列、明细查询、定时任务配置
- 连接器(A 文档/知识库,B 企业系统,C 外部数据)接入后按数据源聚合

## 3. 首页总览(H1)

### 定位

登录后第一屏:回答"有没有要批的、上次那个审到哪了、系统正常吗"。

### 布局

```
顶栏:Sparkii · 工作台 | ●本机运行 · 审计✓ | 审批角标 | 账号 | 主题 | 设置
左栏:智能体列表(状态点/排队徽标)+ 审批中心/审计
主区:
  问候:工作台 · 上午好,{用户名}
  待你处理卡片:待审批/待复核列表,含风险徽标与倒计时,查看全部 → 审批中心
  系统状态卡片:本机运行 / 模型已连接 / 审计已开启
  智能体卡片:每个智能体一张(名称 + 运行/空闲/排队状态),点击进入表面
  最近会话:跨智能体的会话记录(智能体/会话/状态/时间),点击回到对应表面
底部状态栏:一句话状态 + 运行 3/4 · 排队入口
```

### 交互

- 待处理数量同步审批角标;为空时显示"没有待审批事项"空态。
- 智能体卡片状态来自运行池(运行中/排队位次);排队超出上限时显示"排队 N"。
- 最近会话按时间倒序,支持"继续上次"心智。

### 依赖后端

- 待审批列表(`listPendingApprovals` 已有)
- 会话列表/最近运行接口(当前 pilot 无,需新增)
- Agent 运行状态与排队位次接口(进程池状态暴露)
- 系统健康:模型连接状态、审计状态(设置页测试连接可复用)

## 4. 落地注意事项

- 每个表面落地时,先写"表面 brief"(本文档对应小节)再动代码;数据未就绪的区块必须显示真实空态,不得放演示假数据。
- 壳层能力(会话抽屉/队列/审批/审计/主题)已通用,新表面直接复用,不需要改 Shell。
- 每个表面的 widget 仍走组件注册表 + JSON schema 通道(profile 驱动),避免为单表面写死 UI。
