先把问题拆清楚：这是两个不同的问题

诊断基于逐行读码，非猜测
问题 A · 缺 UI

前端完全没有「工作区」这一层

项目对工作区是隐形的：卡片只显示名称/甲方/进度，工作台顶栏只有项目名和版本号。

  • workspacePath 全程不在界面任何地方出现
  • 没有文件树，看不到 input/、manuscript/、figures/、versions/ 里有什么
  • 没有「在文件夹中打开」入口
问题 B · 运行时 bug

对话里「无法对工作区文件读写」

这是真实 bug，不是界面问题。根因集中在上一轮 P9 的「建会话即释放槽位」序列。

  • 文件工具执行前必须有活跃 Task Grant（runtime-action-router.ts:413,481）
  • 释放槽位发出的 new_session 可能产生迟到的 agent_settled，被 ipc.ts:731 当作任务结束撤销 grant → TASK_REVOKED
  • 次要：openProject 补建会话后未 ensureSkeleton → WORKSPACE_NOT_CREATED

补充设计：知识库绑定的 UI / UX

原本缺失 · 本次新增
现状 gap

代码里有，设计稿里缺

产品代码其实已实现知识库绑定，但原设计稿只有一行静态文字，没有可交互入口。核对结果：

  • 创建向导第 ③ 知识库 步已有数据集勾选（index.tsx:619,642-656），创建时 setSessionKnowledge 绑定
  • 准备阶段工作台只有只读文字「已绑定知识库：…」（index.tsx:714）— 代码注释写"可稍后补录"，但界面不能改
  • 原设计稿仅一处静态文字（旧第 263 行），未体现绑定/更换交互

本次补齐：顶栏新增常驻「知识库」入口（popover 内勾选 + 应用/取消），setup 与写作后都能改；准备阶段面板保留摘要。右侧展示创建向导第③步样式。

设计原则

两处露出，职责不同

✓ ① 基本信息 ✓ ② 项目资料 ③ 知识库
公司知识库（可选，可稍后补录）
公司制度库
制度、流程、规范文档已选 ✓
历史标书库
过往中标标书与模板已选 ✓
行业规范库
国标 / 行业标准
列表来自知识库后端 listDatasets() 动态返回，名称/数量不固定；未检测到连接时显示"可跳过"（向导与准备阶段均需此降级文案）。
  • 两条独立通道：公司知识库 = 外部 RAG 检索 + 会话内存绑定；项目私有资料 = 落盘 input/ + T1 索引。二者数据落点/索引/绑定机制都不同，不要混为一谈。
  • 向导第③步：首次创建时勾选 → 写 project.json.knowledgeBases 并 setSessionKnowledge 绑定会话。
  • 准备阶段「更换」：勾选为草稿态，须点「应用绑定」才提交（setSessionKnowledge + writeProject + 刷新）；取消则回滚。补录/调整与"可稍后补录"承诺一致。
  • 写作后仍可改（v2 修订）：知识库绑定与"存放位置"性质不同 —— 换检索源是低风险操作，写作中途发现缺库是常见需求。因此绑定入口放在顶栏常驻（与"工作区"并列），setup / drafting 全程可改，改后立即对后续检索生效、不影响已写正文。准备阶段面板里只保留摘要 +「前往设置」指引，面板消失不影响修改。
  • 存放位置则相反：搬目录高风险，写作后锁定（方案 C）。两者生命周期不同，不要混用。
